*待驗證功能*
cookie jwt 後端發行簽證資訊給前端存入cookie 

密碼加密 (bcrypt):

使用 bcrypt 進行密碼雜湊
salt rounds 設為 10 (在 User model)
每次雜湊都會產生不同結果
Token 加密 (JWT):

使用 HS512 演算法 (比預設的 HS256 更安全)
Token 包含時間戳記防止重放攻擊
移除 15 分鐘後自動過期




驗證流程:

檢查 Authorization header
驗證 token 簽名
移除 檢查過期時間
將使用者資訊加入 request
錯誤處理:

統一的錯誤訊息格式
不洩露敏感錯誤資訊
詳細記錄錯誤但只回傳安全訊息

非阻塞部分
  Node.js 本身就是基於事件迴圈和非阻塞 I/O 模型設計，但在檔案讀寫、網路請求、資撩庫驅動如果不使用異步操作(EX: fs.readFileSync)
  就會使Node.js事件迴圈被阻塞，引此採用大量一步I/O操作(EX: async/awiat處理請求)
